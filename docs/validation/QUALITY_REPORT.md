# Отчёт о качестве метамодели (фаза 3d, Q-18)

Первый выпуск отчёта. Практика заимствована у Exocortex (D-0016, E2): качество метамодели
измеряется, а не декларируется. Числовые разделы воспроизводимы: `npm test`
(`schema:all` + `examples:all` + `quality:check`).

## 1. Вердикт

**Метамодель 0.15.0 (стадия `review`) готова к переходу в фазу 4 (планирование реализации)
с тремя оговорками:**

1. **Q-70 (F-3.29):** канон не покрывает сценарий «проект с задачами» — 3 из 9 конкретных типов
   ядра MVP (`Project`, `Task`, `Article`) отсутствуют в `examples/vault/`. Решение пользователя
   (доукомплектовать / зафиксировать сокращение / отложить) желательно до старта фазы 4: канон —
   тестовое хранилище плагина в фазе 5.
2. **Редакционная очередь** каталога и схемы (не блокирует): F-3.28 (description `title` — схема
   0.16.0), F-3.31 (дубли `meta.r9/r10` ↔ `media.r1/r2` — каталог 0.17.0), F-3.5 (warn-слой целых
   годов не формализован правилом), F-3.7 (предел длины `title`).
3. Ворота фазы 3 («Примеры проходят валидацию схемой и `SchemaEngine`») выполнены **эквивалентом**:
   `SchemaEngine` — модуль фазы 5, его роль в песочнице играет двухпроходная валидация
   `tools/examples/check.cjs` (нормативный алгоритм F-3.17). Формальная приёмка модуля — в фазе 5.

Заморозка ядра (D-0056) не нарушалась: единственное расширение за фазу 3 — `ObjectType.type_id`
— проведено через ADR-0012.

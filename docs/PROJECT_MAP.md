# Карта проекта: метамодель личной базы знаний + плагин Obsidian

> **Назначение файла.** Единственный «источник правды» о состоянии проекта. Обновляется после каждого
> утверждённого решения. Если контекст сессии потерян — чтение этого файла + `docs/context/CONTEXT_SNAPSHOT.md`
> восстанавливает картину.

## 1. Цель

1. Доработать существующую метамодель личной базы знаний «Second Brain» (черновики в Markdown, сгенерированные ИИ).
2. Зафиксировать метамодель в документации и артефактах (описание, JSON Schema, TS-типы, YAML-примеры).
3. Довести до состояния «готова к реализации»: ядро, этапы, модули (реализуемые / отложенные / нереализуемые).
4. Реализовать MVP плагина Obsidian со стабильным ядром.

**Рамки MVP:** TypeScript, esbuild, Svelte или vanilla TS (React — только при явной необходимости),
локально и офлайн, без внешних API и LLM, тесты, semver. Мобильная поддержка не обязательна.

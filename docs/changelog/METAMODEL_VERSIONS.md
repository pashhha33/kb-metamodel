## Легенда стадий

| Стадия | Значение |
|---|---|
| `draft (каркас)` | есть структура документов, содержание не наполнено |
| `draft` | ядро метамодели описано, но не согласовано |
| `review` | ядро согласовано, идёт доработка атрибутов, связей, валидации |
| `stable` | пройден чек-лист «метамодель утверждена», разрешена реализация плагина |

## Правило синхронизации

Каждая строка этой таблицы обязана иметь соответствующую запись в `CHANGELOG.md` и, при наличии
ломающих изменений, ссылку на ADR.

Имена артефактов схемы содержат версию метамодели (D-0061, D-0062):

| Артефакт | Имя | Статус |
|---|---|---|
| Точка входа схемы | `schema/metamodel-<version>.schema.json` | источник истины |
| Фрагменты схемы | `schema/<version>/common/*.json`, `schema/<version>/m1/*.json` | источник истины |
| Единый файл схемы | `schema/dist/metamodel-<version>.bundle.json` | **производный**, собирается `npm run schema:bundle` |
| TypeScript-типы | `src/generated/metamodel-<version>.types.ts` | **производный**, генерируется `npm run schema:types` |
| Матрица покрытия правил | `docs/validation/RULES_COVERAGE.md`, `docs/validation/rules-coverage.json` | **производный**, генерируется `npm run schema:coverage` |
| Результат прогона | `docs/validation/SCHEMA_VALIDATION_RUN.md` | **производный**, генерируется `npm run schema:validate` |

Каталог версии (`schema/<version>/`) существует в единственном экземпляре на версию: фрагменты
разных версий не смешиваются. Производные файлы не редактируются руками и пересобираются;
расхождение между ними и источником считается ошибкой сборки.

Версия схемы равна версии метамодели, для которой она нормативна. Схема версии N описывает
данные версии N; поддержка данных более ранних версий — задача миграций, а не схемы.
